Hamburger Menu Icon 햄버거 메뉴 아이콘

An icon, usually three horizontal lines, representing entry to a menu.

Menu buttons on mobile and narrow screens.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Kebab Menu Icon 케밥 메뉴 아이콘

A vertical three-dot icon representing additional options.

Additional actions for individual items.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Meatball Menu Icon 미트볼 메뉴 아이콘

A horizontal three-dot icon representing additional options.

Additional actions in toolbars and cards.

This is also commonly called a horizontal ellipsis.

Reference

Chevron Icon 셰브런 아이콘

A directional icon formed by two short angled strokes.

Collapsing, expanding, previous, and next actions.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Caret Icon 캐럿 아이콘

A small triangular or angled symbol indicating a direction.

Dropdowns and sort direction.

Distinguish this from caret meaning a text insertion cursor.

Reference

Disclosure Indicator 상세 공개 표시

An indicator suggesting that further detail or child items are available.

Navigating from settings rows and expanding trees.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Close Icon 닫기 아이콘

An icon, usually an X, representing closing the current panel or window.

Closing modals, tabs, and panels.

Do not treat close, cancel, and delete as equivalent actions.

Reference

Back Arrow 뒤로 가기 화살표

An indicator returning to the previous screen or navigation step.

Page and screen navigation.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

External Link Icon 외부 링크 아이콘

An icon indicating a link outside the current service or into another context.

Links to external documents and new windows.

The icon alone does not determine whether a new window opens.

Reference

Drag Handle Icon 드래그 핸들 아이콘

Dots or stacked lines marking an area that can be grabbed and dragged.

Reordering lists.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Grip 그립

A handle-like visual cue indicating that an element can be manipulated.

Panel resizing and drag-start regions.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Expand Icon 확장 아이콘

An icon representing enlargement or expansion of content or an area.

Expanding panels and entering full screen.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Collapse Icon 축소·접기 아이콘

An icon representing reduction or collapse of an expanded area.

Collapsing panels and lists.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Pin Icon 고정 아이콘

An icon representing keeping an item visible or fixing it at a particular position.

Frequently used items and pinned panels.

Its function differs from a location pin on a map.

Reference

Visibility Icon 가시성 아이콘

An eye or similar icon indicating visibility, hiding, or a visibility toggle.

Showing layers and passwords.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Lock Icon 잠금 아이콘

An icon indicating restricted editing, protection, or a locked state.

Layer locking and permission states.

Do not imply verified security or encryption merely from this symbol.

Reference

Link Icon 연결 아이콘

A chain or similar icon representing a link, connection, or dependency.

Inserting URLs and linking objects.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Refresh Icon 새로고침 아이콘

An icon representing reloading data or refreshing a screen.

Refreshing and reloading lists.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference

Sync Icon 동기화 아이콘

An icon representing synchronization of data or states between sides.

Synchronizing cloud and offline data.

Refreshing is different from bidirectional data synchronization.

Reference

Undo / Redo Icon 실행 취소·다시 실행 아이콘

Icons representing reversal of an edit or reapplication of an undone edit.

Editors and action histories.

These are mainly conventional shape names or functional descriptions. They may not exactly match a package's search keys.

Reference
