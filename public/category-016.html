Bar Chart 막대 차트

Compares categorical values using bar lengths measured from a common baseline.

Use when designing comparison & ranking and selecting analytical visualizations.

A histogram shows frequency in numeric intervals, not arbitrary categories.

Reference

Stacked Bar Chart 누적 막대 차트

Stacks segments to show category totals and their composition.

Use when designing comparison & ranking and selecting analytical visualizations.

Upper segments lack a shared baseline, making precise comparison harder.

Reference

Horizontal Bar Chart 가로 막대 차트

Places categories on the vertical axis and encodes values as horizontal lengths.

Use when designing comparison & ranking and selecting analytical visualizations.

Useful for long labels and ranking; preserve a zero baseline for lengths.

Reference

Grouped Bar Chart 그룹 막대 차트

Places series side by side within each category.

Use when designing comparison & ranking and selecting analytical visualizations.

Supports direct series comparison rather than totals, unlike stacked bars.

Reference

100% Stacked Bar Chart 100% 누적 막대 차트

Normalizes each category to 100% to compare composition.

Use when designing comparison & ranking and selecting analytical visualizations.

Absolute size differences disappear; provide totals separately.

Reference

Diverging Bar Chart 발산형 막대 차트

Extends values on opposite sides of a meaningful baseline.

Use when designing comparison & ranking and selecting analytical visualizations.

State whether the center represents zero or a neutral response.

Reference

Lollipop Chart 롤리팝 차트

Uses a dot for value and a thin stem to the baseline.

Use when designing comparison & ranking and selecting analytical visualizations.

Lighter than bars, but small markers may be harder to read.

Reference

Dot Plot 점 도표

Compares category values using dot positions on a shared scale.

Use when designing comparison & ranking and selecting analytical visualizations.

Unlike a scatterplot, this compares categories against a quantitative scale.

Reference

Dumbbell Chart 덤벨 차트

Connects two values per category to emphasize their difference.

Use when designing comparison & ranking and selecting analytical visualizations.

The connector encodes a difference, not an observed path between times.

Reference

Slope Chart 슬로프 차트

Connects each entity across two time points to show change.

Use when designing comparison & ranking and selecting analytical visualizations.

Highlights change and rank shifts, without showing intermediate observations.

Reference

Bump Chart 범프 차트

Tracks changes in rank over multiple time points.

Use when designing comparison & ranking and selecting analytical visualizations.

The axis represents ranks, not magnitudes; label the direction of rank 1.

Reference

Bullet Chart 불릿 차트

Combines an actual-value bar, a target marker and performance bands.

Use when designing comparison & ranking and selecting analytical visualizations.

Target markers and background bands have different meanings.

Reference

Pareto Chart 파레토 차트

Pairs descending bars with a cumulative percentage line.

Use when designing comparison & ranking and selecting analytical visualizations.

Bars use the original unit while the line uses cumulative percent.

Reference
