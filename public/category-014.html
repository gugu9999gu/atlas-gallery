Dashboards & metrics

KPI Card KPI 카드

Summarizes a key metric with its target or comparison context.

Use when designing dashboards & metrics and selecting analytical visualizations.

Unlike a bare stat card, it includes performance context.

Reference

Stat Card 통계 카드

Displays one statistical value and its unit.

Use when designing dashboards & metrics and selecting analytical visualizations.

It does not require a target or change comparison.

Reference

Gauge 게이지

Positions a value on a scale or within target bands.

Use when designing dashboards & metrics and selecting analytical visualizations.

Represents a measured state rather than task completion.

Reference

Dashboard Widget 대시보드 위젯

An individual dashboard panel answering one analytical question.

Use when designing dashboards & metrics and selecting analytical visualizations.

It is one titled, actionable unit, not the full dashboard.

Reference

Metric Comparison 지표 비교

Compares the same metric across two periods or groups.

Use when designing dashboards & metrics and selecting analytical visualizations.

Keep period length, aggregation and units comparable.

Reference

Delta Indicator 증감 표시기

Displays an absolute or relative change from a baseline.

Use when designing dashboards & metrics and selecting analytical visualizations.

An increase is not always positive; higher error rates can be worse.

Reference

Dashboard Layout 대시보드 레이아웃

Organizes metrics, trends and detail tables by analytical priority.

Use when designing dashboards & metrics and selecting analytical visualizations.

Prioritize analytical questions and comparable layouts over widget count.

Reference

Target vs Actual 목표 대비 실적

Use when designing dashboards & metrics and selecting analytical visualizations.

Small Multiples 스몰 멀티플

Benchmark Line 벤치마크 기준선

Reference

Anomaly Annotation 이상치 주석

Use when designing dashboards & metrics and selecting analytical visualizations.

Data Freshness Indicator 데이터 최신성 표시

Use when designing dashboards & metrics and selecting analytical visualizations.

Empty Chart State 차트 빈 상태
