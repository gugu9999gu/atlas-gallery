같은 모양이라고 같은 개념은 아닙니다

진행 링은 알려진 작업 완료율을, 도넛 차트는 여러 부분의 구성비를, 게이지는 값과 범위를 나타냅니다. 원형 진행 표시기는 확정형·불확정형을 포함하는 상위 개념입니다. 상세 화면의 구분 포인트와 비교 패널에서 차이를 확인할 수 있습니다.

미리보기의 범위

차트와 UI 예시는 자체 제작한 SVG·CSS 도식입니다. 명시적으로 대응되는 패턴은 항목별 시각 예시를 제공하고, 추상적인 원리나 실행 환경이 필요한 기술은 해당 개념의 설명·적용 관계를 담은 개념 도식으로 표시합니다. 모든 카드가 해당 라이브러리나 게임 엔진을 실제 실행하는 것은 아닙니다.

모든 차트 수치는 가상 예시입니다. 실제 고객·기업·시장·연구 데이터를 나타내지 않습니다. 장식·게임 효과는 설명용 시각화이며 광과민성 위험을 줄이기 위해 빠른 점멸을 피하고 모션 정지와 동작 줄이기를 지원합니다.

편집·출처 원칙

한국어 설명과 영어 번역은 편집된 요약이며 각 제품 제공자의 공식 번역이 아닙니다. 일반 명칭·제품명·API 명칭을 구분하고, 동일한 개념의 다른 이름은 대표 항목에 별칭으로 연결합니다. 원본 식별자는 유지합니다.

참고 문서 링크는 추가 학습 경로입니다. 모든 외부 페이지·패키지의 최신성, 라이선스, 보안, 실행 결과를 전수 검증했다는 의미는 아닙니다. 도입 전 해당 프로젝트의 공식 문서를 확인하세요.

Read, see and distinguish design.

ATLAS Gallery is an editorial reference spanning web design, UI/UX, games, maps, 3D, icons, motion and implementation libraries. It is operated by 스투피아드.

A similar shape does not imply the same meaning

A progress ring communicates known task completion; a donut chart shows composition; a gauge compares a measurement with a scale. Circular progress indicator is a family including determinate and indeterminate forms. Use the distinction notes and comparison panels to understand these relationships.

What the previews represent

The illustrations use original SVG and CSS. Explicitly mapped patterns have specific visual examples. Abstract ideas and environment-dependent technologies have concept / application diagrams instead. Not every card runs the named library or game engine.

All chart values are synthetic. They do not represent real customers, companies, markets or studies. Effects are explanatory visuals. Motion can be paused and reduced-motion preferences are respected.

Editorial and source policy

Definitions and English translations are editorial summaries, not official translations by the product owners. Generic terminology, products and APIs are distinguished; exact synonyms redirect to a canonical record while source identifiers are retained.

Sources are further-reading paths, not a claim that every external page, license, security property or implementation has been independently reverified. Check the official project documentation before adoption.
