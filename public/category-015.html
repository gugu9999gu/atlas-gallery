Sparkline 스파크라인

A compact trend line embedded next to a value or in a table.

Use when designing trends & time and selecting analytical visualizations.

It supplements nearby context rather than replacing a fully labeled chart.

Reference

Line Chart 선 차트

Connects ordered observations to reveal trends.

Use when designing trends & time and selecting analytical visualizations.

Connecting unordered categories can imply continuity that does not exist.

Reference

Area Chart 영역 차트

Fills the region under a line to emphasize change and magnitude.

Use when designing trends & time and selecting analytical visualizations.

The filled area suggests magnitude; choose the baseline carefully.

Reference

Multi-series Line Chart 다중 선 차트

Compares several series on a shared time axis.

Use when designing trends & time and selecting analytical visualizations.

Use direct labels or selective highlighting when many series overlap.

Reference

Step Chart 계단 차트

Shows a value holding steady until it changes at an event.

Use when designing trends & time and selecting analytical visualizations.

Appropriate for quantities that remain constant between changes.

Reference

Stacked Area Chart 누적 영역 차트

Shows total size and series contributions over time as stacked areas.

Use when designing trends & time and selecting analytical visualizations.

Middle layers are harder to compare because their baseline moves.

Reference

Streamgraph 스트림그래프

Arranges time-series layers around a varying central baseline.

Use when designing trends & time and selecting analytical visualizations.

Useful for pattern exploration, less suitable for exact comparisons.

Reference

Combo Chart 혼합 차트

Combines marks such as bars and lines in one coordinate system.

Use when designing trends & time and selecting analytical visualizations.

Clearly distinguish units and scales when using a secondary axis.

Reference

Candlestick Chart 캔들스틱 차트

Uses a body and wick to encode open, high, low and close.

Use when designing trends & time and selecting analytical visualizations.

The body spans open to close; the wick spans low to high.

Reference

OHLC Chart OHLC 차트

Shows open, high, low and close with a range line and side ticks.

Use when designing trends & time and selecting analytical visualizations.

Encodes the same four values as a candlestick without a filled body.

Reference

Gantt Chart 간트 차트

Places task intervals as horizontal bars on a time axis.

Use when designing trends & time and selecting analytical visualizations.

Bar length represents duration, not a performance magnitude.

Reference

Event Timeline 이벤트 타임라인

Places discrete events and descriptions along a timeline.

Use when designing trends & time and selecting analytical visualizations.

A Gantt chart emphasizes intervals; an event timeline emphasizes points in time.
