Data Tooltip 차트 툴팁

Shows values and units for a focused or hovered chart mark.

Use when designing analytical exploration and selecting analytical visualizations.

A UI tooltip explains a control; a data tooltip details an observation.

Reference

Drill-down 드릴다운

Navigates from an aggregate to a finer level in the same hierarchy.

Use when designing analytical exploration and selecting analytical visualizations.

Drill-through opens a separate detail context.

Reference

Cross-filtering 교차 필터링

Uses a selection in one view to filter related views.

Use when designing analytical exploration and selecting analytical visualizations.

Expose filter scope and provide an obvious reset.

Reference

Date Range Filter 기간 필터

Selects the analysis date range and optional comparison period.

Use when designing analytical exploration and selecting analytical visualizations.

Clarify time zone, inclusion of today and partial periods.

Reference

Interactive Legend 인터랙티브 범례

Allows users to highlight or toggle series from the legend.

Use when designing analytical exploration and selecting analytical visualizations.

Communicate hidden states with symbols or labels as well as color.

Reference

Crosshair Cursor 십자선 커서

Adds horizontal and vertical guide lines at a chart position.

Use when designing analytical exploration and selecting analytical visualizations.

These are axis-reading guides, not merely a pointer icon.

Reference

Brushing 브러시 선택

Selects observations by drawing a region on a chart.

Use when designing analytical exploration and selecting analytical visualizations.

Selection is not deletion; provide a clear reset action.

Reference

Linked Highlighting 연결 강조

Highlights matching records across views without removing other records.

Use when designing analytical exploration and selecting analytical visualizations.

Cross-filtering removes nonmatching data; highlighting leaves it visible.

Reference

Drill-through 드릴스루

Opens a separate detailed report while preserving selection context.

Use when designing analytical exploration and selecting analytical visualizations.

Unlike drill-down, it changes the report context rather than just hierarchy level.

Reference

Focus + Context 포커스와 컨텍스트

Pairs a detailed zoomed view with an overview of the full range.

Use when designing analytical exploration and selecting analytical visualizations.

Keep the zoomed range identifiable within the whole.

Reference

Metric Selector 지표 선택기

Changes the numerical metric shown in a visualization.

Use when designing analytical exploration and selecting analytical visualizations.

Different from a dimension selector; update units together with the metric.

Reference

Dimension Selector 차원 선택기

Changes the categorical grouping such as channel or product.

Use when designing analytical exploration and selecting analytical visualizations.

Changes grouping while keeping the measure definition explicit.

Reference

Aggregation Selector 집계 선택기

Selects a summary operation such as sum, mean or median.

Use when designing analytical exploration and selecting analytical visualizations.

An average of averages may differ from the overall mean.

Reference

Comparison Period Toggle 비교 기간 전환

Switches the baseline to a prior period or year-over-year period.

Use when designing analytical exploration and selecting analytical visualizations.

Consider calendar alignment and equal period lengths.

Reference

Chart Type Switcher 차트 유형 전환기

Switches between compatible visual encodings of the same data.

Use when designing analytical exploration and selecting analytical visualizations.

Not every dataset is suitable for every chart type.

Reference

Chart Data Table 차트 데이터 표

Provides a tabular alternative for the values used in a chart.
