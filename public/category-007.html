Icon Roles & Meanings

Open an entry for its visual reference, comparisons and source-language text.

Icon Button 아이콘 버튼

An interactive button whose main content is an icon.

Toolbars, closing panels, and running searches.

Implement the icon image separately from the button's role and keyboard behavior.

Reference

Iconography 아이코노그래피

A system for consistently designing icon meaning, shape, weight, and usage.

Establishing product-wide icon rules.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Glyph 글리프

The drawn form of a character or symbol; in UI terminology, also a compact monochrome icon.

Describing the forms of font glyphs and interface symbols.

A glyph is not necessarily an icon; character glyphs are included too.

Reference

Icon 아이콘

A concise pictorial symbol representing an object, function, or state.

Communicating UI meanings such as search, save, and warnings.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Pictogram 픽토그램

A simplified picture representing an object or action for communication or guidance.

Facility guidance, safety signs, and transportation signage.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Symbol 심볼

A broad term for a sign expressing an agreed meaning.

Defining brand, mathematical, status, and functional symbols.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

System Icon 시스템 아이콘

An icon representing a common action or object within an operating system or interface system.

Representing files, settings, networks, and sharing.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

App Icon 앱 아이콘

The identifying image for an application, used in launchers, stores, and similar locations.

Identifying an application's brand.

Requirements differ from ordinary functional icons within a screen.

Reference

Favicon 파비콘

A site's identifying icon shown in browser tabs, bookmarks, and related places.

Identifying a website.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Functional Icon 기능 아이콘

An icon representing an action that can be performed through interaction.

Print, delete, and search buttons.

The accessible name should describe the action rather than the icon's appearance.

Reference

Decorative Icon 장식 아이콘

An icon used for decoration or atmosphere without adding meaning.

Decorations beside text and background patterns.

Avoid unnecessary repeated announcements by assistive technologies.

Reference

Informative Icon 정보 아이콘

An icon communicating content meaning or classification without itself being a control.

File types, delivery methods, and document categories.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Status Icon 상태 아이콘

An icon indicating a current state, such as success, error, or synchronization.

Status indicators in tables, task lists, and toolbars.

It can be combined with badges, color, and text, but is not inherently a button.

Reference

Brand Icon 브랜드 아이콘

An icon identifying a company, service, or product brand.

Social sign-in and external service connections.

Check trademark rules in addition to the icon license.

Reference

Icon Label 아이콘 라벨

Text accompanying an icon to state its function or meaning.

Explaining unfamiliar features and important actions.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Leading Icon 선행 아이콘

An icon placed before text or input content.

Distinguishing input types and menu items.

The leading position can change with the language's reading direction.

Reference

Trailing Icon 후행 아이콘

An icon placed after text or input content.

Suggesting expansion, clearing, or navigation to details.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.

Reference

Icon Metaphor 아이콘 메타포

Representing a digital function by borrowing the meaning of a physical object.

Representing deletion with a trash can and search with a magnifying glass.

Specify both shape and role. Do not assume an image has the same meaning across all languages and cultures.
